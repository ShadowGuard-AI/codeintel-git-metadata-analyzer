codeintel-git-metadata-analyzer

The Ring Record. A git metadata analyzer that reads the record a repository has written into itself, its authors, its commit messages, and its branch names, and scores the entries that break its patterns.

The repository main.py
History by gitGit runs as argument lists with no shell; author addresses are counted from the log
Rare authorsAn address is anomalous when its share of commits falls below one minus the threshold, under a tenth at the default 0.9
Subjects onlyCommit messages are checked by subject line alone; bodies are never read, and remote branches are never examined
Flat weightsThe risk score adds fixed weights by kind, never by amount, and caps at 1.0

Usage

python3 main.py REPO_PATH [--email_threshold 0.9] [--commit_message_pattern PATTERN] [--branch_name_pattern PATTERN] [--output_file analysis_report.txt] [--offensive_tools]

The README usage line is a placeholder naming an executable the repo does not ship; the real invocation is the one above. The default message pattern expects a capitalised type word and a colon at the head of the subject. The default branch pattern accepts only feature, bugfix, hotfix, or release prefixes in lowercase, under which a lone main branch is itself an invalid name.

OptionWhat it does
repo_pathThe repository to read. Required. The README parameter list omits it; the code requires it.
--email_thresholdDefault 0.9. The README list gives this No description provided; the help text in main.py gives the default.
--commit_message_patternThe subject line pattern, default ^[A-Z][a-z]+: followed by text.
--branch_name_patternThe local branch name pattern, with feature, bugfix, hotfix, and release prefixes by default.
--output_fileWhere the report goes. Default analysis_report.txt.
--offensive_toolsAdds a run of bandit, flake8, pylint, and pyre over the tree; each tool that produces output adds 0.4 to the score.

How the score is built

  • The weights are flat: 0.3 for any email anomaly, 0.2 for any invalid message, 0.1 for any invalid branch. One odd address scores exactly as much as half the history being odd.
  • Only local branches are judged, so the state of the remote says nothing either way.
  • A repository whose only branch is main fails the branch check on that fact alone.

Requirements

Python, plus the four external analyzers listed in the requirements file (bandit, flake8, pylint, and pyre-check, each 1.0.0 or later), which the code invokes only when --offensive_tools is passed.
